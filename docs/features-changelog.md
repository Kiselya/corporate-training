## Базовый функционал (ТЗ — MVP)

### 1. Диаграмма Ганта (35 баллов)
- Кастомный SVG (React), не библиотека — полный контроль
- 3 масштаба: неделя / месяц / квартал
- Прогресс внутри полос (визуальное заполнение)
- Тултипы с бизнес-данными при наведении (курс, участники, прогресс)
- Линия "Сегодня" (красная пунктирная)
- Цветовая кодировка статусов (планируется / в процессе / завершено / отменено)
- readOnly режим для роли USER
- **Фильтр по компании** — множественный выбор с поиском
- **Кнопка печати** — landscape A4, CSS скрывает UI-элементы
- Клик по полосе → переход в карточку группы

### 2. Учёт обучения и прогресс (25 баллов)
- CRUD: группы, курсы, сотрудники, компании, спецификации
- Прогресс каждого участника (0-100%)
- Средний прогресс группы (среднее арифметическое)
- Расчёт стоимости: `цена × участники × (1 - скидка/100)`
- Фиксация цены на момент создания группы
- Автообновление статусов (PLANNED → IN_PROGRESS → COMPLETED) при запросе

### 3. Финансовый учёт
- Спецификации: subtotal + НДС 22% + итого
- Скидки (ручные и по промокоду) — применяются во всех расчётах
- История цен (PriceHistory) — при изменении цены старая сохраняется
- CSV-экспорт отчётов (BOM + ";" для Excel с кириллицей)

### 4. XML-интеграция с Global ERP (20 баллов)
- Импорт: Edu_Participant, Edu_Course (батч, несколько файлов)
- Экспорт: employee, course, group → XML
- Маппинг перепутанных полей ERP (sMiddleName = имя, sFirstName = отчество)
- Drag & drop загрузка файлов
- Лог интеграции (created/updated/errored для каждого файла)

## Бонусный функционал (сверх ТЗ)

### 5. Система ролей и безопасности
- 3 роли: SUPER_ADMIN, ADMIN, USER
- JWT аутентификация (jsonwebtoken + jose для Edge Runtime)
- Мультитенантность: ADMIN видит только данные своей компании
- **Изоляция данных**: сотрудники, группы, компании — фильтруются по companyId
- **Защита API от подмены ID**: ADMIN получает 403 при попытке просмотра чужих данных
- Имперсонация (SUPER_ADMIN входит под другим пользователем)
- Инвайт-ссылки (1:N — один инвайт для нескольких пользователей)
- Каскадное удаление (Employee → GroupMember)

### 6. Управление пользователями
- **Назначение прав из профиля сотрудника** — кнопка "Назначить права" → создаёт аккаунт с ролью
- **Создание пользователя из админки** — выбор сотрудника + роль + пароль
- **Смена роли** — суперадмин меняет роль любого пользователя
- Поиск и сортировка в таблице пользователей (по роли: SUPER_ADMIN → ADMIN → USER)
- Блокировка/разблокировка пользователей

### 7. Карточка компании
- Клик по названию → детальная страница
- KPI: сотрудников, курсов, спецификаций, общая сумма с НДС
- Таблица сотрудников с прогрессом (клик → профиль)
- Учебные группы компании
- Спецификации с суммами
- **Доступные курсы** — назначение/удаление курсов компании (CompanyCourse)

### 8. Дашборд (3 вкладки)
- Финансовый: оборот по месяцам, по курсам, топ-5 дорогих групп
- Аналитический: популярность курсов, прогресс, завершаемость
- Управленческий: статусы, ближайшие обучения, конфликты
- **Фильтр по компании** — множественный выбор с поиском
- **Stacked bar chart** — оборот по месяцам с разбивкой по компаниям (уникальные цвета)
- **Цветные чипсы** — каждая компания со своим цветом
- Экспорт CSV / Сохранение PDF

### 9. Проверка уникальности сотрудника (ТЗ 3.1)
- При создании: если ФИО + компания совпадает — предупреждение
- Пользователь может подтвердить или отменить

### 10. Обнаружение конфликтов расписания
- Сотрудник записан на два курса в пересекающиеся даты
- Две группы по одному курсу пересекаются

### 11. Модули курса
- Типы: лекция, практика, тест, задание
- Порядок, длительность
- CRUD из карточки курса

### 12. Soft delete с корзиной
- JSON-снимок данных перед удалением
- SUPER_ADMIN может восстановить

### 13. Промокоды
- Создание, валидация, лимит использований, срок действия
- Скидка применяется к группе

### 14. Короткие URL
- `/courses/0001` вместо `/courses/cmnk9st1g000nymuv6jg30awy`
- `/employees/0048` вместо длинного CUID
- API принимает id, code и erpId

### 15. Docker
- `Dockerfile` + `docker-compose.yml`
- Одна команда: `docker compose up --build`
- PostgreSQL + App в одном стеке

### 16. Печать
- Landscape A4, минимальные отступы
- Скрытие UI-элементов (сайдбар, фильтры, кнопки)
- Принудительная печать фоновых цветов
- Карточки не разрываются между страницами
